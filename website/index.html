WORKSPACE

LOCAL + SSH

Worminal

Close the window. Keep the work.

Your shells, web tools and remote machines, together in a small Linux terminal.

Your work outlives its windows.

Close every window. Come back to the same tabs, shells and running programs. The background service owns your terminal sessions; windows are views into them.

$worminal --attach

Reattach to the existing workspace. No shell commands are replayed.

Live updates ↗Build & install ↗

Multiple machines. One interface.

Keep local and SSH-backed tabs in the same window. Remote shells live in their host’s daemon and keep running when the view disconnects. A headless Linux host needs only the service.

$worminal --master user@host

Replace user@host with your SSH destination. Compatible peers sync daemon versions and merge Worminal configuration on connection.

Remote installation ↗Enrolled devices ↗

Make a web document part of your workflow.

Open a web page or local HTML tool beside your shells. A shell command can turn its current tab into a browser view. Build a file explorer, report or dashboard as a document you can edit and reload.

$worminal --new-browser-tab report.html

Example: open your local report.html. Local tools have a limited, read-only file and directory API. No terminal rebuild needed.

Browser capabilities ↗

Agents can work with your actual sessions.

A discoverable native API lets agents find tabs, read screens and retained output, wait for changes, and send guarded input locally or over SSH. Inspection preserves your focus, scroll position and terminal size.

$worminald api help

Optional shell integration reports command completion and exit status. Passive inspection does not start a service.
