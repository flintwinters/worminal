Worminal: a persistent Linux terminal

A small Linux terminal emulator for persistent shells, web tools and remote machines.

Sessions SSH Web tools Agents

Persistent terminal sessions.

Close every window. Come back to the same tabs, shells and running programs. The background service owns your terminal sessions; windows are views into them.

$worminal --attach

Reopen existing tabs without starting a new shell.

Live updates ↗Build & install ↗

Local and SSH sessions, together.

Keep local and SSH-backed tabs in the same window. Remote shells live in their host’s daemon and keep running when the view disconnects. A headless Linux host needs only the service.

$worminal --master user@host

Replace user@host with your SSH destination. Compatible peers sync daemon versions and merge Worminal configuration on connection.

HTML tools beside your shell.

Open a web page or local HTML tool beside your shells. A shell command can turn its current tab into a browser view. Build a file explorer, report or dashboard as a document you can edit and reload.

$worminal --new-browser-tab report.html

Example: open your local report.html. Local tools have a limited, read-only file and directory API. Reload the document to see your changes.

A native API for terminal agents.

The native API lets agents list tabs, read current and past output, wait for changes, and send input locally or over SSH. Inspection preserves your focus, scroll position and terminal size.

$worminald api help

Optional input guards reject requests if the foreground program changes. Shell integration reports when commands finish and their exit status.
