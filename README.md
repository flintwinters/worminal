# Worminal

Worminal is a small Linux terminal built around a simple idea: closing a window shouldn't end your work. Your shells and tabs live in a background service, so you can close every window and come back while your programs keep running. The service can also live on another machine, with the same local interface over SSH. A built-in browser keeps documentation and local tools beside your shells. Keep the interface small, memory use low, and the work independent of the window. Built with Rust, GTK, WebKitGTK, and a terminal engine derived from [st](https://git.suckless.org/st/); see [LICENSE](LICENSE).
