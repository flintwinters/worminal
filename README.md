# Worminal

A small Linux terminal that keeps your work running.

- **Leave and come back.** Close every window. Reopen your tabs with your shells and programs still running.
- **Work across machines.** Use the same terminal interface locally and over SSH.
- **Keep tools together.** Put shells, web pages and local HTML tools side by side in tabs and split panes.
- **Update without stopping.** Replace open windows while terminal sessions keep running. Browser pages reload.

Built with Rust, GTK and WebKitGTK, with a terminal engine derived from [st](https://git.suckless.org/st/).
